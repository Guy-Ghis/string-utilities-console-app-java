# string-utilities-console-app-java
A simple interactive Java console application offering a suite of string-related tools.

---
## Features
This CLI app allows users to:

- ✅ Check if a string is a **palindrome**
- 📦 **Compress** a string using basic run-length encoding
- 🔄 **Reverse** the words in a sentence
- 🔇 **Remove vowels** from a string
- 🔐 **Validate password** strength
All functions are bundled in a single utility class (`StringUtilities`)

---
## How to Run
### Prerequisites
- Java 11 or higher installed
- Terminal or command prompt

### Compile
```bash
javac Main.java StringUtilities.java
```

### Run
```bash
java Main
```
